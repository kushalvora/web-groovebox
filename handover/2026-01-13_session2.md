## Project Overview

A web-based groovebox inspired by the Roland MC-101, built as a learning tool for music production fundamentals. Uses React + TypeScript + Vite + Tailwind CSS + Zustand + Web Audio API.

**Target User**: Someone with basic music exposure who wants to learn production fundamentals through hands-on building.

### 2. Second Oscillator (Osc2)
Added ability to layer a second oscillator for thicker sounds.

**New Track Properties:**
```typescript
osc2Enabled: boolean;      // Toggle on/off
osc2Type: OscillatorType;  // sine/square/sawtooth/triangle
osc2Detune: number;        // -100 to +100 cents
osc2Volume: number;        // 0-1 mix level
```

**UI:** In SynthControls - ON/OFF toggle, waveform buttons, detune slider, volume slider

**Audio:** Both oscillators mix before the filter: `(Osc1 + Osc2) → Filter → Envelope → Output`

---

### 3. Legato Mode (Tie/Sustain)
Added ability to connect consecutive active steps into one long sustained note.

**New Track Property:**
```typescript
legato: boolean;  // false = trigger mode, true = legato mode
```

**Behavior:**
- **TRIGGER** (default): Each active step triggers a new note
- **LEGATO**: Consecutive active steps play as ONE note; gap = release

```
Without Legato:  ●  ●  ●  ○  ●  →  [note][note][note]   [note]
With Legato:     ●  ●  ●  ○  ●  →  [====long note====]  [note]
```

**Files Modified:**
- `src/store/useGrooveboxStore.ts` - Added osc2/legato properties, actions, migration
- `src/audio/Synthesizer.ts` - Dual oscillators, `playLegato()`, `releaseNote()` methods
- `src/components/Transport/Transport.tsx` - Legato playback logic with state tracking
- `src/components/SynthControls/SynthControls.tsx` - Osc2 controls, TRIGGER/LEGATO toggle

## Track Data Model (Current)

```typescript
interface Track {
  id: string;
  name: string;
  type: 'drum' | 'tone';
```

## What's Next: Scene-Based Pattern Arrangement (Phase B)

A plan was created but not yet implemented. Key features:

### Pattern Slots
- 4 slots per track (A, B, C, D) instead of 1
- Edit different patterns without losing previous work

### Scenes
- A scene defines which slot plays on each track
- Scene 1: all tracks play slot A
- Scene 2: drums slot A, bass slot B, lead slot B
- etc.

### Scene Triggering
- Click a scene to queue it
- At end of current bar (step 0), switch to queued scene
- Smooth musical transitions

### UI (SceneLauncher)

## How to Test New Features

### Oscillator 2:
1. Select Track 3 (Bass) or Track 4 (Lead)
2. In SYNTH CONTROLS, find OSCILLATOR 2 section
3. Click ON to enable
4. Set detune to +7ct for subtle chorus effect
5. Adjust volume to taste
6. Play - sound should be thicker/richer

### Legato Mode:
1. Select a synth track (Track 3 or 4)
2. In SYNTH CONTROLS, click LEGATO button (instead of TRIGGER)
3. Draw 4+ consecutive active steps on the sequencer
4. Play - should hear one long sustained note instead of 4 separate notes
5. Leave a gap (inactive step) - note should release, then new note on next active
