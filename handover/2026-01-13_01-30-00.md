## Project Overview

A web-based groovebox inspired by the Roland MC-101, built as a learning tool for music production fundamentals. The project uses a phased approach, implementing one feature at a time to deeply understand each music concept.

**Target User**: Someone with basic music exposure who wants to learn production fundamentals through hands-on building.

**Primary Learning Focus**: Rhythm & timing, mixing, and synthesis with a house/techno genre focus.

### Phase 4 Bonus: Clock Divider ✅

**Features Implemented:**
- Per-track clock division options:
  - **1/4x** - Quarter speed (plays every 4th global step)
  - **1/2x** - Half speed (plays every 2nd global step)
  - **1x** - Normal speed
  - **2x** - Double speed (plays twice per step)
- Visual selector buttons in mixer per track

**Music Concepts Covered:**
- Polyrhythms: Different tracks at different tempos
- Half-time feel: Drums at 1x, bass at 1/2x
- Double-time fills: Drums at 2x for buildup sections

**Technical Notes - Clock Divider:**
```javascript
// Example: 1/2x divider - only play on even global steps
if (globalStep % 2 === 0) {
  trackStep = Math.floor(globalStep / 2);
  // Play pattern at trackStep
}
```

**Music Concepts Covered:**
- Oscillators: Raw waveforms with different characters
- Subtractive synthesis: Start with harmonics, filter away
- Envelopes: How sounds evolve over time
- Filters: The most important effect in electronic music

**Technical Notes - Synth Signal Flow:**
```
Oscillator → Filter (Lowpass) → Envelope (Gain) → Track Output
```

**Preset Defaults:**

## Track Data Model

```typescript
interface Track {
  id: string;
  name: string;
  type: 'drum' | 'tone';
  patterns: DrumPatterns;      // For drum tracks
  synthPattern: SynthPattern;  // For synth tracks
  mute: boolean;
  solo: boolean;
  volume: number;              // 0-1
  pan: number;                 // -1 to 1
  clockDivider: 0.25 | 0.5 | 1 | 2;
  // Synth settings
  synthPreset: 'bass' | 'lead' | 'pad' | 'stab';
  oscillatorType: 'sine' | 'square' | 'sawtooth' | 'triangle';
  filterCutoff: number;        // 0-1
  filterResonance: number;     // 0-1
  attack: number;              // 0-1
  release: number;             // 0-1
}
```

## How to Test New Features

### Clock Divider:
1. Create a drum pattern on Track 1 at 1x
2. Create a bass line on Track 3
3. Set Track 3 clock divider to 1/2x
4. Hit play - bass plays at half speed (half-time feel)

### Synthesizer:
1. Click "DRUM" badge on Track 3 or 4 to toggle to "SYNTH"
2. Click steps to add notes
3. Use +/- buttons to change pitch
4. Use Octave buttons to shift all active notes

### Mixing:
1. Program patterns on multiple tracks
2. Adjust volume faders to balance
3. Pan tracks left/right for stereo width
4. Use Solo to isolate a track
5. Use Mute to remove a track temporarily
