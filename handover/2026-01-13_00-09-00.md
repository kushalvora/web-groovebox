## Project Overview

A web-based groovebox inspired by the Roland MC-101, built as a learning tool for music production fundamentals. The project uses a phased approach, implementing one feature at a time to deeply understand each music concept.

**Target User**: Someone with basic music exposure who wants to learn production fundamentals through hands-on building.

**Primary Learning Focus**: Rhythm & timing concepts, with a house/techno genre focus.

### Phase 2: Step Sequencer ✅

**Files Created:**

**Features Implemented:**

- Visual playhead showing current step
- Preset patterns: Empty, Four on the Floor, Classic House, Driving Techno

**Music Concepts Covered:**
- Step sequencing vs real-time recording
- 4/4 time signature
- Four-on-the-floor pattern (foundation of house/techno)
- Velocity and dynamics
- Quantization

**Technical Notes - Drum Synthesis:**
```
Kick:  Sine oscillator with pitch envelope (150Hz → 50Hz)
Snare: Triangle oscillator + filtered noise
Hi-Hat: Bandpass + highpass filtered noise (short decay)
Open Hat: Same as hi-hat but longer decay
```

## How to Test Swing

1. Load "Classic House" preset
2. Set swing to 0% - note the mechanical, straight timing
3. Gradually increase to 50% - hear the hi-hats start to "shuffle"
4. Compare with "Driving Techno" at 0% swing for that hard, straight feel
