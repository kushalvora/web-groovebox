## Project Overview

A web-based groovebox inspired by the Roland MC-101, built as a learning tool for music production fundamentals. Uses React + TypeScript + Vite + Tailwind CSS + Zustand + Web Audio API.

**Target User**: Someone with basic music exposure who wants to learn production fundamentals through hands-on building.

**Live URL**: (to be deployed on Vercel)

## What Was Accomplished This Session

### 1. Fixed Clock Divider Bug
When a track had clock divided by 0.5x or 0.25x, steps 8-15 never played because `trackStep` only reached 0-7 before the pattern cycled.

**Solution**: Added per-track step counters that persist across global pattern cycles.

**File Modified:**
- `src/components/Transport/Transport.tsx` - Added `trackStepCountersRef`, updated `shouldTrackPlayOnStep()`

### 3. Variable Pattern Length (8-64 Steps)

Each track can now have its own pattern length: 8, 16, 32, or 64 steps.

**New Track Property:**
```typescript
patternLength: 8 | 16 | 32 | 64;  // Default: 16
```

**Features:**
- Per-track pattern length selector in Step Sequencer header
- Patterns resize when length changes (extend with empty steps / truncate)
- Horizontal scrolling for 32/64 step patterns
- Global loop length = max of all track pattern lengths

**Files Modified:**
- `src/store/useGrooveboxStore.ts` - Added `PatternLength` type, `patternLength` to Track, `setTrackPatternLength` action
- `src/audio/Scheduler.ts` - Added `setPatternLength()` method, dynamic loop length
- `src/components/Transport/Transport.tsx` - Uses max pattern length, track-specific step wrapping
- `src/components/Sequencer/StepSequencer.tsx` - Dynamic grid, length selector dropdown, scrollable container

---

### 4. Sample-Based Drum Loading

Drums can now use loaded audio samples (WAV/MP3) instead of synthesis. Synthesis remains as fallback.

**New DrumSampler Methods:**
```typescript
setSample(type: DrumType, buffer: AudioBuffer): void;
clearSample(type: DrumType): void;
hasSample(type: DrumType): boolean;
```

**New AudioEngine Method:**
```typescript
decodeAudioFile(file: File | Blob): Promise<AudioBuffer>;
```

**UI:**
- Each drum row has a `+` button to load a sample
- Green `S` indicator shows when sample is loaded (click to clear/revert to synth)

**Files Modified:**
- `src/audio/AudioEngine.ts` - Added `decodeAudioFile()`, `decodeAudioUrl()`
- `src/audio/DrumSampler.ts` - Added sample storage, `playSample()`, hybrid play logic
- `src/components/Sequencer/StepSequencer.tsx` - Sample loading UI per drum row

## Track Data Model (Current)

```typescript
interface Track {
  id: string;
  name: string;
  type: 'drum' | 'tone';
  patterns: DrumPatterns;
  synthPattern: SynthPattern;
  mute: boolean;
  solo: boolean;
  volume: number;              // 0-1
  pan: number;                 // -1 to 1
  clockDivider: 0.25 | 0.5 | 1 | 2;
  patternLength: 8 | 16 | 32 | 64;  // NEW

  // Synth settings
  synthPreset: SynthPreset;    // Now includes 9 presets
  oscillatorType: OscillatorType;
  filterCutoff: number;
  filterResonance: number;
  attack: number;
  release: number;

  // Second oscillator
  osc2Enabled: boolean;
  osc2Type: OscillatorType;
  osc2Detune: number;
  osc2Volume: number;

  // Legato mode
  legato: boolean;
}
```

## How to Test New Features

### Variable Pattern Length:
1. Select any track
2. In Step Sequencer header, use "Steps" dropdown to change to 32 or 64
3. Pattern grid should extend with scrolling
4. Play - pattern should loop at new length

### Sample Loading:
1. Select a drum track (Track 1 or 2)
2. Click the `+` button next to any drum name (Kick, Snare, etc.)
3. Select a WAV or MP3 file
4. Button changes to green `S` - sample is loaded
5. Play - should hear your sample instead of synth
6. Click `S` to clear and revert to synthesis

### New Synth Presets:
1. Select a synth track (Track 3 or 4)
2. In SYNTH CONTROLS, try new presets: Sub, Acid, Pluck, Organ, Bells
3. Each has distinct sound characteristics

### Clock Divider Fix:
1. Select any track
2. Set clock divider to 0.5x (in Mixer)
3. Program notes/drums on steps 8-15
4. Play - should now hear those steps (after first global pattern cycle)
